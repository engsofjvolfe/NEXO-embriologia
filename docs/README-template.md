# Template de README (para leitura por qualquer pessoa)

*Este arquivo é um modelo, não um documento final. Copie-o pra escrever*
*qualquer README do projeto (o da raiz, ou o de um módulo específico,*
*dentro de `modulos/<nome>/`), preencha os campos entre colchetes e*
*apague os textos em itálico (como este) antes de considerar o*
*documento pronto.*

*Público-alvo deste tipo de documento: alguém que nunca leu uma linha*
*de código e não precisa disso pra entender o que o projeto é, por que*
*ele existe e em que pé está. Nenhum termo técnico entra sem explicação*
*ao lado, em linguagem comum, no mesmo lugar onde ele aparece — a*
*mesma regra de [Respostas ao usuário](../.claude/CLAUDE.md) do*
*projeto, aplicada agora à documentação, não só à conversa.*
